개인정보처리방침 / Privacy Policy

최종 수정일 / Last updated: 2026-11-22

1. 접근하는 정보 / Data accessed

Hermes Mail은 사용자가 Google OAuth로 명시적으로 승인한 Gmail 계정의 메일(메일 본문, 헤더, 첨부파일, 폴더/라벨)에 IMAP으로 접근합니다.

With the user's explicit Google OAuth consent, Hermes Mail accesses the authorized Gmail account's messages (bodies, headers, attachments, folders/labels) over IMAP.

2. 이용 목적 / How data is used

메일을 읽고 요약·분류하며 답장 초안을 작성하는 데에만 사용합니다. 광고, 프로파일링, 판매 목적으로 사용하지 않습니다.

Data is used only to read, summarize and organize mail and to prepare reply drafts. It is never used for advertising, profiling or sale.

3. 저장과 보안 / Storage and security

모든 처리는 운영자 본인의 컴퓨터에서 이루어집니다. OAuth 토큰은 macOS 키체인에 저장되며, 메일 데이터를 별도 서버로 전송하거나 제3자와 공유하지 않습니다. 메일 내용 처리에 AI 모델이 사용될 수 있으며, 이는 운영자가 선택한 모델 제공자의 약관을 따릅니다.

All processing happens on the operator's own computer. OAuth tokens are stored in the macOS Keychain. Mail data is not transferred to any separate server or shared with third parties. An AI model chosen by the operator may process message content, subject to that model provider's terms.

4. Google API 사용자 데이터 정책 / Google API Services User Data Policy

Hermes Mail의 Google API 데이터 사용 및 이전은 제한적 사용(Limited Use) 요건을 포함한 Google API Services User Data Policy를 준수합니다.

Hermes Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. 접근 철회 / Revoking access

언제든지 Google 계정 → 서드파티 액세스에서 Hermes Mail의 접근 권한을 철회할 수 있습니다.

Access can be revoked at any time at Google Account → Third-party access.
